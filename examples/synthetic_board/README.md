# Synthetic preview board

Original test artwork, not a functional electrical circuit and not manufacturing-ready.
Board: 30 x 20 mm, bottom copper with two 3 mm pads connected by a 1 mm trace, 1 mm drill hits at (5,10) and (25,10), matching closed rectangular outline. All coordinates share the same origin. No mirroring. Intended for adapter and future 2D viewer smoke tests.
