# RES-020 — Offline nominal XYZ motion preview

Status: submitted for CI. Previous tool-library commit df8ba75cccb03fe53751a1cbbc6df0c449fc0eef passed all workflows (183 research tests per OS).

Pure domain DepthSetup requires explicit thickness, positive safe Z and nonnegative breakthrough limit. Positive requested depth magnitude maps to negative work Z. Through operations must reach nominal board thickness without exceeding the explicitly modeled breakthrough interval; isolation must remain shallower. Equal depth increments use ceil(depth / max stepdown), final level exact. Cap depth levels and event count. These checks are nominal, not stock or spoilboard measurements. V-bit remains single-depth.

Expand each bound stage into offline tool_setup markers and continuous nominal XYZ events: rapid XY only at assumed safe height, vertical plunge, cutting XY at constant depth, full retract. One marker per stage even for same tool ID. Each path and depth level retracts, including separate tab segments and drill levels. No spindle command, real tool change, coordinate transforms, machine limits, fixtures, plunge capability, peck-cycle optimization or tool length compensation. Drill tip geometry is not modeled; nominal depth alone does not guarantee full diameter through the board. No G-code, hardware or UI. Diagnostics retained; manufacturing_ready always false. Stage order inherited. Length metrics distinguish cut XY, rapid XY and vertical travel, not time. Tests verify continuity, depth schedule, stage ordering, tab gaps, mismatch rejection and actual synthetic import. All values in test fixtures are illustrative, not machine settings.
