# RES-016 — Compensated cutout and straight tabs

Status: submitted for CI. Inspected FlatCAM Evo CutOutGen.py at c948622f6b906f9910990d7bafbfb3012be21350 (blob 27494d9d6f9fd35c2eabd85333a76e2e9edbc3d5), notably offset_contours and _cutout_intervals. Independent implementation for canonical board centerline polygons, so no Gerber stroke-width compensation is needed here. No upstream code copied.

Offset outward from the exterior and inward into each internal cutout by nominal tool radius plus positive experimental margin (0.002 mm). Reject collapsed/split insets and invalid contours. Explicit stock boundary required. Validate nominal centerline distance from retained board and stock edges, including cutouts. Straight tab anchors on original exterior project to the offset contour. Gap length is requested nominal tab width plus cutter diameter; reject curved or overlapping gaps and interference with other cuts. Internal paths are listed first; no internal tabs or slug retention. No assertion of actual final cutout dimensions (positive margin and tool corner radius leave material), tab strength, fixture clearance or physical safety. No Z depths, feeds, G-code, GUI or machine control. All output is preview-only. Tests include analytic dimensions, four tabs, internal cutout, direction, invalid placement/stock/tool, and imported synthetic board. Direct FlatCAM cutout comparison and real KiCad validation pending.
