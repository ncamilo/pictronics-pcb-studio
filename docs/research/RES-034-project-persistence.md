# RES-034 — Visible holding gaps and portable project persistence

Baseline 950512c passed all four workflows. User reported holding tabs were difficult to see. Previous overlay used the same color as the cutout and depended on its visibility. Show distinct high-contrast solid pink gap markers with T1..Tn labels and count (including zero). Markers indicate compensated centerline gaps, not a volumetric retention guarantee. No implicit default tabs. Independent test reconstructs actual NC cut segments after reflection at both depths and checks nominal gap-center clearance.

Version 1 .pcbstudio.json embeds original source bytes, role, filename and SHA-256. Reparse embedded sources in controlled temporary files; no archive paths executed or extracted to arbitrary locations. Recompute CAM from settings rather than trusting stored motion. Restore work frame, tab positions, CAM settings and last successfully exported nominal NC setup/process settings. Save via atomic replacement. Invalid archive, checksum, version or regenerated geometry fails before replacing current view. No controller state, hardware connection, execution resume, machine settings, viewport or unsaved dialog edits persisted. Source input budget 32 MiB each / 64 MiB total; archive 128 MiB.
