# RES-017 — Direct cutout comparison

Status: submitted for CI. Original FlatCAM offset_contours and any_cutout_handler run in pinned upstream environment. Contour records supplied explicitly, not a test of outline_contours or Gerber stroke reconstruction. Matched canonical zero-width inputs, radius 0.5 mm, margin 0.002 mm. Five fixtures: rectangle, four tabs, rectangular inner window, concave outline, inaccessible 0.8 mm window. Compare line length, discrete Hausdorff, nominal swept symmetric difference, gap length, independent anchors, inner count and cut/gap partition. FlatCAM uses default buffer resolution (16 segments/quadrant), Studio 64. Preliminary fixture-specific thresholds: length 0.01 mm, discrete Hausdorff 0.002 mm, swept difference 0.02 mm²; no exact equivalence required across different tessellations. For an inaccessible window, expect empty upstream offset and explicit Studio rejection rather than a partial plan. Path component counts may differ due to closed contour seam splitting. No Z, tab strength, clamping, physical machining, full upstream job or real PCB validation. Results pending. No production code changed.
