# RES-021 — Independent offline motion conformance validator

Status: submitted for CI. Prior commit e518b9f1fd140695491699abf3e82ca5be256efd passed all workflows, including 206 research tests per OS and reference https://github.com/ncamilo/pictronics-pcb-studio/actions/runs/45891593817.

Validate the canonical trace by consuming events against original bound CAM source records, without calling the motion generator or its path helper. Verify stage order, source index/type/diameter, feature counts, tool identity, depth schedule, continuity, XY vertices and direction, feed, full retractions, setup/rapid at nominal safe height, no unplanned/trailing events. Return observed nominal tip bounds, measured travel and retained diagnostic codes; fail at first discrepancy. Exact XY and 1e-12 mm depth comparison tolerance are numerical conventions. Equivalent subdivided/reordered traces are not accepted. Mutation tests deliberately alter coordinates, continuity, feed, stages, tool IDs, gap crossings and sequence completeness. This is independent trace conformance, not independent reconstruction of source geometry or physical collision detection; shared nominal tool geometry is not calibrated. No machine bounds verification, fixtures, spindle, tool length, G-code, UI, or machine execution. Manufacturing readiness always false. No new upstream source copied.
