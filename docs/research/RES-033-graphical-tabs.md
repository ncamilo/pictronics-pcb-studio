# RES-033 — Graphical exterior tab placement

Reference: pinned FlatCAM Evo CutOutGen.py, manual gap projection and automatic side midpoint presets (RES-032). Reuse Studio's existing compensated cutout engine, no copied upstream code. Add modal editor inside CAM dialog, canonical source XY, pixel-based snap radius, left-add/right-remove, two/four presets, clear and fit. Render actual compensated centerline and removed gap (width + cutter diameter); invalid layouts leave last valid selection intact. Presets are geometric candidates, not guaranteed to fit concave shapes or curved edges. Existing engine rejects corners, overlapping tabs and insufficient modeled stock. Only full-height exterior tabs, no internal retention, thin tabs or mouse bites yet. Accepted anchors are passed to ordinary CAM planner; cancel leaves CAM settings unchanged. Reopening CAM restores last successful settings. No changes to physical readiness. User requested bCNC-inspired grouped toolbar later; record in roadmap. Eight new test cases submitted to desktop CI; actual PWM user verification pending. Main unchanged.
Main CAM overlay also marks tab gaps as dashed amber when the exterior stage is visible. Load the tab editor lazily so the basic desktop shell does not require the optional geometry stack before opening the editor. Accept/cancel integration tested separately.
