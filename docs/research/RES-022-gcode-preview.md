# RES-022 — Offline G-code rendering and readback

Status: submitted for CI. Prior commit 89383255c36a397e9cdb67d9d7b81a29f06760b8 passed all workflows, 225 research tests per OS.

Render validated nominal XYZ events to explicit G21/G90/G94 and G0/G1 words inside a semicolon comment envelope on every line. START and STAGE are preview metadata, not controller commands. No spindle commands, real tool changes, work offsets, homing, coordinate transforms, G-code file export, or hardware interface. Do not strip comments or stream this text. A separate restricted parser reads only this envelope and supported grammar, reconstructs absolute positions, feed and stage index, verifies nominal safe Z and compares every event against the validated source without invoking the renderer. Six decimal places and 0.000000501 mm maximum component discrepancy are serialization bounds, not machine precision. Count collapsed moves due to quantization; preview only, not acceptable as a runnable program. No general modal G-code interpretation or full GRBL compatibility claim. Synthetic test fixtures and nominal setup only. Tests cover full integrated board, bad modes, unwrapped lines, unsupported words, coordinate/depth/feed tampering and extra/missing motions. No main or GUI changes. Manufacturing readiness always false. Real machine profile, fixture checks, tool changes/spindle sequencing, safe initialization and real KiCad files still pending.
